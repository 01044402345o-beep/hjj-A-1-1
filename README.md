# 나만의 프롬프트 관리 프로그램

GenAI 프롬프트를 카테고리별로 정리하고 검색·즐겨찾기할 수 있는 Python 콘솔 프로그램입니다.
메모장과 노션에 흩어져 있던 프롬프트를 한곳에서 관리하는 것이 목표입니다.

## 실행 방법

Python 3.10 이상이 필요합니다. 외부 라이브러리는 설치하지 않아도 됩니다.

```bash
git clone https://github.com/01044402345o-beep/hjj-A-1-1.git
cd hjj-A-1-1
python prompt_manager.py
```

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력해 새 프롬프트를 등록합니다. 빈 값은 다시 입력을 요청합니다. |
| 2 | 프롬프트 목록 | 전체 프롬프트를 번호·카테고리·제목·즐겨찾기(⭐)와 함께 출력합니다. |
| 3 | 카테고리별 조회 | 카테고리를 골라 해당 프롬프트만 봅니다. |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드가 들어간 프롬프트를 찾습니다. 대소문자를 구분하지 않습니다. |
| 5 | 프롬프트 상세 보기 | 번호를 입력해 내용 전문을 확인합니다. |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기를 추가하거나 해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기된 프롬프트만 모아 봅니다. |
| 8 | JSON 파일로 저장 | 현재 목록을 `data/prompts.json`에 저장합니다. |
| 9 | JSON 파일에서 불러오기 | 저장해둔 파일을 읽어 목록을 교체합니다. |
| 10 | Markdown으로 내보내기 | 카테고리별 `.md` 파일을 `export/` 폴더에 만듭니다. |
| 0 | 종료 | 프로그램을 끝냅니다. |

프로그램은 자동 저장을 하지 않습니다. 8번을 직접 고르지 않으면 종료 시 변경 사항이
사라집니다.

## 프롬프트 카테고리

기본으로 6개 카테고리에 프롬프트가 하나씩 등록되어 있습니다.

| 카테고리 | 설명 | 기본 프롬프트 |
|---|---|---|
| 텍스트 생성 | 글쓰기·요약·번역 등 텍스트 결과물을 만드는 프롬프트 | 블로그 글 작성 도우미 |
| 이미지 생성 | 이미지 생성 모델에 넣을 화풍·구도·비율 키워드 | 제품 썸네일 생성 |
| 영상 생성 | 영상 기획·스크립트·장면 구성용 프롬프트 | 숏폼 광고 스크립트 작성 |
| 페르소나 | 모델에게 역할과 말투를 부여하는 프롬프트 | IT 컨설턴트 페르소나 |
| 자동화 | 노코드 도구와 연결해 반복 처리에 쓰는 프롬프트 | 뉴스 요약 자동화 프롬프트 |
| 기타 | 위 분류에 들어가지 않는 프롬프트 | 프롬프트 품질 점검 체크리스트 |

카테고리는 목록에서 고르거나 직접 입력할 수도 있습니다.

### 카테고리를 나눈 기준

프롬프트를 **결과물의 형태**(텍스트/이미지/영상)와 **사용 방식**(페르소나/자동화)으로
나눴습니다. 같은 주제라도 결과물이 다르면 필요한 지시문 구조가 달라지기 때문입니다.
예를 들어 텍스트 생성 프롬프트는 문단 구조와 분량을 지정해야 하지만, 이미지 생성
프롬프트는 화풍·구도·비율 같은 시각 요소를 나열하는 편이 효과적입니다.

## 데이터 구조

프롬프트는 딕셔너리를 담은 리스트로 관리합니다.

```python
prompts = [
    {
        "title": "블로그 글 작성 도우미",
        "content": "당신은 10년 경력의 전문 블로거입니다...",
        "category": "텍스트 생성",
        "favorite": True,
    },
]
```

## 프로젝트 구조

```

```
